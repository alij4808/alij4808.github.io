# Lancelot Charvillat

Personal portfolio: [lacha25.github.io](https://lacha25.github.io/).

This is a static website. No dependencies, build step or deployment workflow are required.

Edit the files in the repository root:

- `index.html` — page structure and metadata.
- `styles.css` — typography and layout.
- `content.js` — projects and their links.
- `app.js` — navigation, About and Contact.
- `room-particles.js` — the interactive particle room.

Keep the `assets/` folder alongside these files. It contains the favicon and tool logos, including their attribution metadata.

For GitHub Pages, open **Settings → Pages**, choose **Deploy from a branch**, then select **main** and **/ (root)**. The `.nojekyll` file enables direct static-file serving.
